# Desperados M.C. Website

This is a simple static website. The main file is `index.html`.

## Edit Upcoming Rides

1. Open `index.html` in a text editor.
2. Search for `Upcoming Rides`.
3. Edit the ride title, date/location, time, and description.
4. Save the file.
5. Upload the changed `index.html` to GitHub.

## Deploy with Vercel

This site needs no build step.

- Framework preset: Other
- Build command: leave blank
- Output directory: leave blank
- Install command: leave blank

Vercel can deploy the repository as a static site.
